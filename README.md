## เปิดใช้งาน

เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
npm run dev
```

หรือดับเบิลคลิก `start.cmd` แล้วเปิด http://localhost:4174/ กด `Ctrl+C` ใน Terminal เพื่อหยุดเซิร์ฟเวอร์

ต้องมี Node.js / npm สำหรับคำสั่ง `npm run dev` และ Python 3 สำหรับ static server ไม่ต้องรัน `npm install` เพราะโปรเจกต์ไม่มี dependencies หากต้องการรันโดยไม่ใช้ npm ให้ใช้ `python -m http.server 4174 --bind 127.0.0.1` จากโฟลเดอร์โปรเจกต์

- Dashboard: http://localhost:4174/#/today
- หน้าแรก / Login mockup: http://localhost:4174/#/login (เปิดเว็บโดยไม่มี route จะเข้าหน้านี้)
- ทดลองเข้าสู่ระบบด้วย Google หรืออีเมลสมมติ เพื่อไปยัง `#/brand-setup` แล้วเชื่อมบัญชีตัวอย่าง → วิเคราะห์จำลอง → สรุปวันนี้ ข้อมูลร้านและสถานะบัญชีบันทึกในเบราว์เซอร์ ไม่มีการยืนยันตัวตนหรือเชื่อมผู้ให้บริการจริง
- ชุดคอมโพเนนต์กลาง: http://localhost:4174/#/components
- คู่มือทีม: `shared/README.md`
- คู่มือให้ AI ติดตั้ง GitHub CLI / สร้าง branch / push / rebase / merge: `TEAM-GIT-WORKFLOW.md`
- แผนที่ปรับแล้ว: `MOCKUP-PAGES.md` (สำเนาของไฟล์ต้นทางที่ผู้ใช้ระบุ)

## ไฟล์หลัก

- `app.js`: ติดตั้ง shell, router, ค้นหาทั้งร้าน, แจ้งเตือน และจุดเชื่อมต่อของหน้าที่จะทำภายหลัง
- `dashboard.js`: หน้า 5 สำหรับ BrandCare AI / ขนมบ้านสวน
- `login.js`, `login.css`: หน้า 1 ยินดีต้อนรับ / Login mockup และจุดเชื่อมต่อหน้าตั้งค่าแบรนด์
- `components.js`: ตัวอย่างคอมโพเนนต์กลางให้ทีมกดดูพฤติกรรม
- `shared/data.js`: ข้อมูลจากข้อ 6 ในแผน
- `shared/ui.js`: ฟังก์ชัน markup และพฤติกรรมที่ใช้ร่วมกัน
- `shared/tokens.css`, `shared/components.css`, `shared/brandcare.css`: ฟอนต์ SF Pro, พื้นขาวเทา ปุ่มสีน้ำเงินตามธีมเดิม การ์ดมุมโค้ง Header บน Desktop และ Bottom nav บนมือถือ

ตัวเลขใน Dashboard: 23 คอมเมนต์, +340%, ยอดขาย ฿48,200 ลดลง 18%, คะแนน 4.8 เป็น 4.5, งานวันนี้ 3 ข้อ และ 11.11 อีก 20 วัน

ทุกข้อมูลเป็น mockup ร้านและลูกค้าเป็นข้อมูลสมมติ หน้า comments / sales ของทีมยังเป็นจุดเชื่อมต่อ ส่วนหน้าเชื่อมข้อมูล วิเคราะห์ และรายการปัญหารวมจาก main แล้ว ไม่มีการเชื่อม API ล็อกอินจริง เรียก AI ส่งข้อความ หรือโพสต์จริง ไม่มีการ deploy

- ตั้งค่า: http://localhost:4174/#/settings

ไฟล์ `jayda.js`, `jayda.css` และ `shared/jayda-data.js` เพิ่มเนื้อหาและพฤติกรรมของทั้ง 5 หน้า โดย router อยู่ใน `app.js` ร่างแคปชัน สถานะอนุมัติ และการตั้งค่าเก็บเฉพาะเบราว์เซอร์นี้ ไม่มีการส่งโพสต์ ข้อความ หรือเรียก AI จริง สถานะล่าสุดแยกแต่ละหน้าอยู่ใน `MOCKUP-TRACKING.md`

บน macOS เครื่องนี้เปิดเว็บด้วย `python3 -m http.server 4174 --bind 127.0.0.1` จากโฟลเดอร์โปรเจกต์ แล้วเข้า URL ด้านบน

แผนโพสต์: AI ร่างจากข้อมูลร้าน เสียงลูกค้า และเทศกาล → ร้านปรับข้อความ → ตรวจข้อมูลและยืนยันการปรับกล่อง → ยืนยันใช้แผน → คัดลอกแต่ละโพสต์ไปเผยแพร่เอง การแก้ร่างจะคืนสถานะรอตรวจ ไม่มีระบบตั้งเวลาโพสต์ในรอบนี้

แชท: คุยต่อได้หลายข้อความ หยุดคำตอบ เปิดบทสนทนาเดิม เริ่มใหม่ และลบได้ เก็บเฉพาะเบราว์เซอร์นี้ (`brandcare-jayda-chats-v1`, สูงสุด 40 บทสนทนา / 100 ข้อความล่าสุดต่อบทสนทนา) คำถาม preset มีคำตอบเฉพาะแต่ละข้อ ส่วนคำถามพิมพ์เองทุกข้อใช้คำตอบตัวอย่างยอดขายเดียวกัน การคิดและ stream เป็นการจำลอง ไม่เรียก AI และไม่มีประวัติข้ามอุปกรณ์

หน้าจัดการบัญชีจากตั้งค่าใช้ `#/connect-data?from=settings` ไม่มี onboarding stepper อ่านข้อมูล `brandcare:connections:v1` ร่วมกับ flow สมัคร เชื่อมเพิ่ม/ยกเลิกและบันทึกกลับตั้งค่าได้ โดยไม่เริ่มวิเคราะห์ใหม่
